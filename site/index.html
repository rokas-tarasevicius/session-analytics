{{RECENT_RELEASES}}

A few good questions.

Does it upload my sessions?

No. Analysis runs locally and the dashboard is served on loopback. Public pricing refreshes send no session data. Exports to a remote endpoint require an explicit option; reading another machine requires your SSH setup. Read the privacy contract.

Is usage value what I actually pay?

No. It is the equivalent value at API list prices, with provider-reported amounts identified separately. Subscription allowances are compared with that value in the Subscription view. Discounts are not modeled.

Can I try it without reading my history?

Yes. Clone the repository and run npm run demo with Node.js 24+. The demo uses synthetic history only and never reads your sessions. The “From source” install option above has the commands.

Can my agent use these analytics?

Yes. Six read-only MCP tools and a bundled agent skill expose the same content-free metrics. You can also use terminal reports and structured exports. Set up MCP.
