Questions

Does it upload my sessions?

No. Analysis runs locally and the dashboard is served on loopback. Public pricing refreshes send no session data. Sending exports to a remote endpoint needs an explicit option, and reading another machine uses your own SSH. Read the privacy contract.

Is usage value what I actually pay?

No. It is the equivalent at API list prices, with provider-reported amounts shown separately. The Subscription view compares it with what your plans include. Discounts are not modelled.

Can I try it without reading my history?

Yes. Clone the repository and run npm run demo with Node.js 24+. It uses synthetic history only and never reads your sessions. The “Demo from source” install option above has the commands.

Can my agent use these analytics?

Yes. Six read-only MCP tools and a bundled agent skill expose the same content-free metrics, alongside terminal reports and structured exports. Set up MCP.
